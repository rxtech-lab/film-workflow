# 智能体

智能体替你操作这个应用。用自然语言说出需求——「做一段 30 秒的欢快音乐，放进片头合成里」「按术语表核对
这些字幕」——它会调用与界面完全相同的那套工具。

在 macOS 上智能体是独立窗口：**Command-Option-0**、菜单中的**智能体**项，或工具栏上的星形按钮。该按钮
上出现小圆点表示有任务正在运行。在 iPhone 和 iPad 上它是一个标签页。

## 会话线程

工作以**线程**为单位组织。每个线程有自己的历史和自己的设置，多个线程可以同时运行——线程列表会显示当前
有多少个正在工作。

- **新建线程**是线程列表上方的 **+** 按钮。
- 删除线程会永久删除它的消息和已保存的摘要。**项目不受影响。**

### 目标项目

每个线程指向一个项目。撰写框会显示当前目标，你也在那里更改它。目标属于线程而不是应用，因此在任务运行
期间切换标签页不会改变它的指向。没有目标的线程会显示**无项目**。

新建线程会以你当前正在查看的内容作为初始目标，这通常正是你想要的。

## 引擎

**设置 › 智能体 › 引擎**设定默认引擎，每个线程都可以在撰写框的选择器中单独覆盖。

- **Apple Intelligence**——完全在设备上运行。它**无法调用工具**，因此能回答问题但不能修改你的项目。
  字幕编辑是例外：它仍然可以提出修改建议。
- **OpenAI 兼容模型**——使用**设置 › AI Provider** 中的端点、密钥和模型，具备完整的工具能力。
- **Claude Code**——`claude` 命令行工具，通过应用自带的 MCP 服务器与应用通信。**仅限 macOS。**
- **Codex**——`codex` 命令行工具，方式相同。**仅限 macOS。**

命令行引擎需要你的 Mac 上已安装相应工具。某个引擎不可用时，设置面板会说明原因而不是把选项藏起来——
一个你能据此行动的说明，比一个消失的选项有用。

应用的 MCP 服务器会在线程需要时自动启动，所以使用命令行引擎无需你手动打开任何开关。

## 权限

**设置 › 智能体 › 权限 › 字幕编辑**控制字幕改动的应用方式：

- **应用前先审阅**（默认）——智能体提出字幕修改建议，由你批准。
- **立即应用**——智能体做出的字幕修改即刻生效。

智能体做的其他事情——创建项目、编辑合成、生成图片——在两种设置下都会立即生效。

开启审阅后，建议会汇总到字幕标签页的**审阅 AI 改动**面板。每条改动都带勾选框；**全选** / **全不选**
方便处理长列表；**应用**提交已勾选的部分，**丢弃**则全部作废。

## 限制

**设置 › 智能体 › 限制 › 每轮工具调用次数**限定智能体在必须给出回答之前可以调用多少次工具。长任务可以
调高；想更早打断陷入循环的模型则调低。

## 撰写

在撰写框中输入并发送。任务运行期间，撰写框会显示**处理中…**和一个停止按钮。

在任务运行期间发送的消息会进入**队列**而不会被丢弃。撰写框会显示有多少条在等待，并提供**合并为一条发送**，
让你把它们合成一次追问。

智能体的回复会以带格式的文本呈现，包括代码块。

## 智能体能做什么

智能体通过与 MCP 服务器相同的那套工具触达应用，因此它的能力与各标签页一一对应：

- **项目**——创建、读取、更新、复制、删除和移动项目；管理项目分组。
- **生成**——生成音乐、旁白和图片。
- **字幕**——创建项目、转写、列出与搜索字幕条目、更新条目、设置说话人、提出修改建议、翻译、管理版本以及导出。
- **Remotion**——列出、读取、写入和编辑合成文件，添加和移除图片与音频，把图片生成到项目中，以及对合成截图。

一个线程实际可用的工具集取决于上面的写入策略：在**应用前先审阅**下，直接写入字幕的工具会被收起，只保留
提出建议的那个。

完整清单以及如何从你自己的软件调用这些工具，见「MCP 服务器」一节。

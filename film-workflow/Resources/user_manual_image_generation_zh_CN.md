# 图片生成

图片标签页用于生成静态图片——分镜画面、封面、风格参考，或任何你需要图示的内容。每次生成的结果都会
留在产出它的项目里。

## 新建项目

点击列表上方的 **+**，然后填写表单。

### 提供方

先选提供方，因为下方的参数会随之变化。

- **OpenAI 兼容**使用**设置 › AI Provider** 中的端点和密钥。
- **Google** 使用你的 Google AI API 密钥。

### 提示词

自由描述你想要的图片。

### 模型

每个提供方都有各自的模型选择器，内容从端点获取。用选择器旁的刷新按钮重新拉取列表——更换端点后或提供方
新增模型时会用到。

## 图像参数

参数部分取决于提供方。

### Google

- **宽高比**
- **分辨率**

横向静帧可以从 5:4 比例、2K 分辨率开始尝试。

### OpenAI 兼容

- **尺寸**——预设，或选**自定义**后明确填写**宽度**和**高度**（像素）。
- **质量**
- **格式**——对支持压缩的格式还可设定**压缩率**百分比。
- **背景**
- **透明背景**——需要输出为 PNG 或 WebP。

## 生成

**生成**按钮在工具栏。结果会加入该项目的生成图片中。

打开**生成的图片**可浏览该项目产出的全部内容。新的一次生成不会覆盖旧结果，因此你可以反复打磨提示词并
横向比较。

## 在别处使用图片

- 音乐项目和 Remotion 项目都接受**参考图片**，用作视觉风格指引。
- 智能体可以直接把图片生成到 Remotion 项目中——这些图片会落在合成的 `public/generated/` 目录，并通过
  `staticFile("generated/<名称>")` 引用。见「Remotion」一节。

## 删除

删除图片项目会永久删除它生成的图片。

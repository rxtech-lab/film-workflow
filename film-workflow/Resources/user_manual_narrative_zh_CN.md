# 旁白

旁白标签页把写好的脚本变成语音。你为每位说话人指定音色，按段落撰写脚本，应用会生成语音并拼接成一条
完整音轨。

## 选择提供方

打开旁白项目，在**基本信息**中设置**提供方**：

- **Azure Speech**——按语言分组的大量音色，可精细控制音高、语速、音量、朗读角色和风格强度。支持一条
  旁白中有多位说话人，并可选择**输出格式**。
- **Gemini**——数量较少但表现力强的音色，通过自然语言表演提示来驱动。每条旁白**最多 2 位说话人**。

切换提供方时，每位说话人在两个提供方下的音色选择都会保留，所以来回切换不会丢失选角。段落级的情绪提示
会在切换时清空，因为它们与提供方绑定。

Azure 需要在**设置 › AI Provider** 中填写**订阅密钥**和**区域或端点**；Gemini 使用 **Google AI API 密钥**。

## 场景、备注与上下文

选择 Gemini 时会出现**场景**部分，包含三个自由文本字段——**场景描述**、**备注**和**上下文**。它们为
模型提供表演所处情境的背景信息，不会被朗读出来。

## 为说话人选角

**说话人**部分用于命名每位说话人并选择音色。

- **添加说话人**会追加一位说话人并自动选一个尚未使用的音色。达到提供方上限后该按钮会消失。
- 每个音色选择器旁的试听按钮会播放样例，方便你在确定前比较。
- 删除说话人不会删除他的台词：其段落会重新分配给剩下的第一位说话人。最后一位说话人无法删除。

### Azure 语音参数

使用 Azure 时，每位说话人都有一个**语音参数**折叠区：

- **音高**、**语速**和**音量**——取值与 SSML 一致，例如 `medium`、`+10%`、`-2st`、`0.9` 或 `+6dB`。
  每个字段都带一个建议值菜单。
- **角色**——音色所扮演的朗读角色。
- **风格强度**——风格施加的强弱，范围 0.01 到 2.0。

**重置参数**会把它们全部恢复为默认值。折叠区标题旁会显示所有非默认设置的摘要，一眼就能看出哪些说话人
被调过。

如果 Azure 音色列表为空，请检查设置中的 Azure 凭据，然后点**重试**。

## 撰写脚本

**脚本（Transcript）**面板以段落列表的形式保存脚本，每段归属一位说话人。用 **+ 说话人名**按钮为该说话人
追加一段。

### 简码

简码是写在双花括号中的行内提示，用于控制表演方式。请通过提示选择器插入，而不是手打——应用会为每种简码
显示对应的参数字段。

它们分为五类：

- **停顿与静音**——`{{pause}}`、`{{break:250ms}}`、`{{break:500ms}}`、`{{break:1000ms}}`。
  Azure 另有 `{{break:strong}}` 和 `{{silence:leading:300ms}}`；Gemini 另有 `{{breath}}`。
- **情绪与表演**——仅 Gemini：`{{whispers|文本}}`、`{{excited|文本}}`、`{{sad|文本}}`、
  `{{laughs}}`、`{{sighs}}`、`{{gasps}}`。
- **强调**——仅 Azure：`{{emphasis:strong|文本}}` 和 `{{emphasis:moderate|文本}}`。
- **读法与发音**——仅 Azure：`{{spell|W3C}}`、`{{say:date:mdy|10/15/2024}}`、`{{say:cardinal|1234}}`、
  `{{say:telephone|555-0199}}`、`{{phoneme:ipa:təˈmeɪtoʊ|tomato}}`、
  `{{sub:World Wide Web Consortium|W3C}}`。
- **语言与标记**——仅 Azure：`{{lang:de-DE|Guten Tag}}` 用于在多语言音色上临时切换语言，
  `{{bookmark:scene1}}` 用于在音频流中打一个命名标记。

提示选择器只会列出当前提供方支持的简码。包裹型简码作用于你已选中的文本。

点击段落中已有的简码标签可以修改它的参数，也可以从同一个菜单删除它。

## 生成

**生成**按钮在工具栏。系统会先显示拼装后的脚本预览——预览中过长的脚本会被截断，但生成的是完整内容——
点**开始生成**开始运行，并有进度视图显示当前进展。

各分段会自动拼接成一个旁白文件。每次运行都会保留：点击工具栏中的**历史记录**可以回放或导出以往的旁白。

## 同时生成字幕

项目表单的**字幕**部分有**随音频一起生成字幕**开关。打开后，在生成旁白的同时会产出一个字幕项目，并出现在
字幕标签页中。

这是获取字幕最准确的方式，因为字幕文本就是你自己的脚本——语音服务只当作时钟使用——说话人也来自你的说话人
列表，而不是靠声音识别。

- **字幕提供方**可让本项目覆盖应用默认值。如果选择了不返回逐词时间的提供方，会出现警告：那样的时间轴是
  估算出来的。此处 Azure 或设备端 Whisper 要准确得多。
- 生成的字幕可以像其他字幕一样编辑和导出——见「字幕」一节。

## 删除

删除旁白项目会同时永久删除它生成的音频。

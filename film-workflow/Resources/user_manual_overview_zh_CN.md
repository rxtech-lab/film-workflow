# 概览

Film Workflow 是面向短视频的制作工具集。它生成视频所需的各个素材——音乐、旁白、字幕、静态图片——
并把它们组装成可渲染的合成，全部在一个应用内完成。这些工作也都可以交给智能体代劳。

## 标签页

每个标签页都是一类素材的工作区，结构一致：左侧是项目列表，右侧是设置表单和结果列表，执行操作的按钮
在工具栏。

- **音乐（Music）**——根据描述生成音轨，可选配歌曲结构和歌词。
- **旁白（Narrative）**——用文字转语音把写好的脚本变成多说话人旁白。
- **字幕（Caption）**——把音频转写为字幕，编辑与重新对时，翻译，并导出 WebVTT、SubRip、纯文本或 JSON。
- **图片（Image）**——生成分镜、封面和参考用的静态图片。
- **Remotion**——搭建并渲染视频合成。**仅限 macOS。**
- **智能体（Agent）**——用自然语言描述需求，让智能体来操作应用。
  在 macOS 上它是独立窗口（Command-Option-0）；在 iPhone 和 iPad 上它是一个标签页。
- **设置（Settings）**——在 iPhone 和 iPad 上，设置是一个标签页；在 macOS 上它在应用菜单里
  （Command-逗号）。

## 项目与分组

每个标签页都以**项目**为单位组织工作。项目保存自己的设置以及由这些设置生成的一切，所以音乐项目会保留
它产出的每一版音频，字幕项目会保留每一个转写版本。

用列表上方的 **+** 按钮新建项目。右键点击项目可重命名、复制、移动或删除。

项目可以收进**分组**：使用 **+** 旁边的**新建分组**，然后把项目拖进去，或从项目的右键菜单里选择
**移动到分组**。分组按标签页各自独立。

删除项目会同时删除它拥有的文件。确认对话框始终会写明具体会删掉什么。

## 各部分如何衔接

各标签页的设计就是为了互相衔接：

- 在**旁白**标签页生成的旁白可以直接作为**字幕**项目的音频来源。这样生成的字幕会保留你原本的文字——
  语音服务只负责提供时间轴——说话人也来自你的旁白，而不是靠声音识别。
- 音乐、旁白和生成的图片都可以作为素材加入 **Remotion** 项目，并在合成中引用。
- **智能体**可以代你在任何标签页创建和编辑项目。

## 文件存放位置

生成的音频、导入的音频、图片、字幕文件、下载的 Whisper 模型以及 Remotion 项目，全部存放在应用自己的
Application Support 目录内。除非你自己导出，否则不会往「文稿」文件夹里写任何内容。

导出一律经过保存面板，目标位置由你选择。

## 开始之前

托管式 AI 功能既可以使用 **RxFilm 点数**，也可以使用您自己的服务商凭据。请在
**设置 › AI Provider › 凭据模式**中选择。

### 使用 RxFilm 点数

1. 打开**设置 › 账户**，登录 RxLab 账户。
2. 在**设置 › AI Provider** 中选择 **RxFilm 点数**，然后选择默认模型。
3. 在 macOS 上，需要充值时使用**账户 › 添加点数**。iPhone 和 iPad 可以使用账户中已有的点数，
   但不会提供跳转到外部购买流程的链接。

在此模式下，应用使用服务器管理的服务商凭据。托管式生成任务会按实际计量用量从账户扣除点数；账户页面会
显示可用余额、进行中任务预留的点数和最近用量。余额不足时，当前操作会显示点数不足提示，不会悄悄切换到
您自己的密钥。

### 使用自己的密钥

选择**使用自己的密钥**，然后按需填写：

- **Google AI API 密钥**——音乐生成、Gemini 语音、Gemini 转写、Google 图像模型。
- **Azure Speech**——Azure 语音与 Azure 转写。填入你的区域（例如 `eastus`），或门户中的任意端点 URL。
- **OpenAI 兼容端点与密钥**——智能体、字幕 AI 任务、OpenAI 转写和 OpenAI 图像模型。适用于 OpenAI 本身，
  也适用于任何兼容同一套 API 的服务，例如 Azure OpenAI、OpenRouter、Ollama 或 LM Studio。

密钥保存在系统钥匙串中，不会以明文写入文件。

设备端 Whisper、Apple Intelligence、Claude Code 和 Codex 仍使用各自的本地或命令行运行环境，不会消耗
RxFilm 点数。设备端 Whisper 的详情见「字幕」一节。

## 获取帮助

- 在 macOS 上，随时可从**帮助**菜单（Command-?）打开本指南。
- 帮助菜单中的**新增功能**列出最近加入的功能。
- 第一次用到某些控件时，旁边会出现小提示气泡。

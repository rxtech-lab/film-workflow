# Remotion

**Remotion 通过 React 组件生成视频。Film Workflow 使用 MotionSwift（基于 Metal 的 Skia）原生编译、预览和渲染合成，无需浏览器、Node、Bun、Chromium 或 Remotion Studio，也没有首次运行时安装步骤。MotionSwift 支持 Remotion 的一个子集：使用不受支持的包、元素或样式的合成会显示错误，而不会渲染。

## 新建项目

点击列表上方的 **+**。编辑器分为两栏：左侧是合成的设置，右侧是 原生预览。

### 基本

- **项目名称**
- **文字叠加**——合成中的标题文字。
- **时长**
- **主题色**
- **分辨率**
- **帧率**

### 提示词

告诉模型你想要什么样的视频——风格、运动、氛围、结构。智能体每次编辑这个合成时都会把它作为上下文，
因此值得认真写，而不要留空。

### 图片

为项目附加图片，它们会作为素材提供给合成。

### 参考图片

一张用作**视觉风格指引**的图片，供智能体编辑合成时参考。它与上面的图片不同：这是方向，不是内容。

### 生成的图片

智能体为该项目生成的图片会出现在这里。它们保存在 `public/generated/` 下，在合成中这样引用：

```
staticFile("generated/<名称>")
```

右键点击可**在访达中显示**或删除。刷新按钮会重新读取该目录。

### 音频

音乐、音效、旁白——任何音频都可以。**添加音频**会把文件复制到 `public/audio/`，然后这样引用：

```
staticFile("audio/<名称>")
```

在音乐标签页生成的音轨、或在旁白标签页生成的旁白，就是通过这种方式进入视频的。

## 构建合成

已内置 Three.js、React Three Fiber、Drei 和 Remotion 的 ThreeCanvas，可用于创建 3D 场景。智能体可以直接使用这些包，无需安装。你可以描述需要的 3D 物体动画、灯光或镜头运动。

输入设定好之后，**用 AI 生成…**会据此构建出一份起始的 `Composition.tsx` 并启动原生预览。请把它当作初稿。

打磨合成是在**智能体窗口**里进行的，而不是这里——智能体可以触及每一个项目，所以合成编辑放在那边。用
Command-Option-0 打开它，然后说出你想要的改动。

**源码**会在带语法高亮的编辑器中打开项目文件。修改代码后按 ⌘S 保存，预览会随之刷新。放弃未保存的修改，或覆盖智能体在你编辑期间改动过的文件之前，都会先请你确认。

## 预览

右侧显示实时合成预览，提供原生播放、暂停、拖动和重新加载控件。源码或素材修改后预览会刷新。同一个合成在时间线中的多个片段拥有独立播放位置，导出不会停止实时预览。

检查器中的**编辑**（或在时间线上双击 Remotion 片段、选择**打开合成**）会在编辑器中就地打开合成：合成的元素成为时间线上的轨道，可以移动和修剪；查看器变为画布，可以拖动和缩放元素；检查器中可修改文字和样式。修改会保存到合成源码。按 Esc 或返回按钮回到序列。

检查器中的**元素**标签页会列出合成中可编辑的元素；在时间线上选中 Remotion 片段时同样可用。选择一个元素即可直接修改其文字和样式；**在画布上编辑…**会打开画布编辑器。保存后时间线预览会立即更新。

由代码生成的文字同样可以编辑。如果标题来自变量、数据列表或组件属性，检查器会列出组成它的每一段文字及其所在行。修改其中一段，代码中只会改动这段文字。标为 **shared** 的文字被多个元素使用，修改后会处处生效。由代码计算得出的文字（例如计数器）可以用 **Replace with Fixed Text…** 替换为固定文字（会先请你确认，撤销可恢复代码），也可以用 **Edit in Code…** 在源码编辑器中打开。

Remotion 片段会在序列中实时播放并随序列一起导出，渲染序列时不再需要先把它们渲染成影片。

地图来自 `@motionswift/map`（OpenStreetMap、Apple Maps 和 Mapbox，支持路线和标记）。Mapbox 样式需要在**设置 → Remotion**中填写访问令牌。

## 渲染

**渲染**按钮在工具栏，合成还没有源码时它是禁用的。

导出面板可设置：

- **分辨率**
- **帧率**
- **保存到**——目标文件夹。

面板会在输出设置旁标出合成自身的分辨率和帧率，方便你看出何时发生了缩放或重采样。

点**立即渲染**确认。渲染过程中会显示进度。

## 删除

删除 Remotion 项目会永久删除它的 Remotion 源码、素材和聊天记录。

## 疑难排解

- **预览无法启动。** 面板会显示编译或素材错误。检查入口文件与导入内容后重新加载；仅支持内置库和项目内的浏览器模块。
- **效果无法导出。** 原生渲染器会明确报告不受支持的包、元素和样式。请使用受支持的 Remotion 子集中的内联样式和由帧驱动的效果。
- **渲染按钮不可用。** 说明合成还没有源码。使用**用 AI 生成…**，或让智能体写一份。
- **预览中缺少素材。** 检查是否通过 `staticFile()` 并带上正确的子目录引用——音频用 `audio/`，
  智能体生成的图片用 `generated/`。

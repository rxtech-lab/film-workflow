# Remotion

**Remotion 标签页仅限 macOS。** 它不会出现在 iPhone 和 iPad 上。

Remotion 用 React 组件构建视频。Film Workflow 在应用内自带了完整的 Remotion 运行时，因此无需安装任何
东西——不需要 Node，不需要包管理器，也不需要终端。Remotion Studio 直接在应用窗口内运行，渲染也就地完成。

运行时会在你第一次使用时自行安装，所以首次启动比之后要慢一些。

## 新建项目

点击列表上方的 **+**。编辑器分为两栏：左侧是合成的设置，右侧是 Studio 预览。

### 基本

- **项目名称**
- **文字叠加**——合成中的标题文字。
- **时长**
- **主题色**
- **分辨率**
- **帧率**

### 提示词

告诉模型你想要什么样的视频——风格、运动、氛围、结构。智能体每次编辑这个合成时都会把它作为上下文，
因此值得认真写，而不要留空。

### 图片

为项目附加图片，它们会作为素材提供给合成。

### 参考图片

一张用作**视觉风格指引**的图片，供智能体编辑合成时参考。它与上面的图片不同：这是方向，不是内容。

### 生成的图片

智能体为该项目生成的图片会出现在这里。它们保存在 `public/generated/` 下，在合成中这样引用：

```
staticFile("generated/<名称>")
```

右键点击可**在访达中显示**或删除。刷新按钮会重新读取该目录。

### 音频

音乐、音效、旁白——任何音频都可以。**添加音频**会把文件复制到 `public/audio/`，然后这样引用：

```
staticFile("audio/<名称>")
```

在音乐标签页生成的音轨、或在旁白标签页生成的旁白，就是通过这种方式进入视频的。

## 构建合成

输入设定好之后，**用 AI 生成…**会据此构建出一份起始的 `Composition.tsx` 并启动 Studio。请把它当作初稿。

打磨合成是在**智能体窗口**里进行的，而不是这里——智能体可以触及每一个项目，所以合成编辑放在那边。用
Command-Option-0 打开它，然后说出你想要的改动。

工具栏中的**查看源码**会以语法高亮显示合成的 TSX。

## 预览

右侧面板针对当前项目运行 **Remotion Studio**。运行时启动期间会显示「正在启动 Remotion Studio…」，
随后显示实时预览。

渲染进行期间预览会暂停，面板会说明这一点。如果运行时启动失败，错误会直接显示在面板里，而不是被隐藏。

## 渲染

**渲染**按钮在工具栏，合成还没有源码时它是禁用的。

导出面板可设置：

- **分辨率**
- **帧率**
- **保存到**——目标文件夹。

面板会在输出设置旁标出合成自身的分辨率和帧率，方便你看出何时发生了缩放或重采样。

点**立即渲染**确认。渲染过程中会显示进度。

## 删除

删除 Remotion 项目会永久删除它的 Remotion 源码、素材和聊天记录。

## 疑难排解

- **Studio 无法启动。** 错误会直接显示在预览面板中。运行时在首次使用时安装到应用自己的支持目录；
  如果上一次运行被中断，退出并重新打开应用即可，启动时会清理残留进程。
- **渲染按钮不可用。** 说明合成还没有源码。使用**用 AI 生成…**，或让智能体写一份。
- **预览中缺少素材。** 检查是否通过 `staticFile()` 并带上正确的子目录引用——音频用 `audio/`，
  智能体生成的图片用 `generated/`。

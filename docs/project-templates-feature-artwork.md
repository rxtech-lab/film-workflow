Generated with the built-in image generation tool for the **Project templates
are here** What's New card. The PNG has a transparent alpha channel and is
bundled as
`film-workflow/Assets.xcassets/WhatsNewProjectTemplates.imageset/project-templates.png`.

footage tile represent reusable project plans adapted with the user's clips.

## Final prompt

Use case: stylized-concept
Asset type: transparent illustration for the RxFilmStudio native macOS What's New feature card.
Primary request: Create a polished flat 2D illustration representing reusable film project templates: a compact stack of three rounded storyboard sheets, with the front sheet showing three ordered cinematic shot thumbnails and a simple editing timeline below them. Each thumbnail depicts a different framing of the same peach sunset and blue ocean: a wide horizon, a closer sun, a shoreline detail. The timeline is made of a few blue and lavender clip blocks aligned into two rows. Include one separate small blue footage tile beside the sheets and a simple curved arrow pointing toward an empty lavender shot slot, communicating bringing your own footage into a template. A single small four-point sparkle suggests agent assistance.
Style/medium: modern editorial vector-like illustration, flat solid fills, clean crisp rounded edges, straight-on front view. Match a native creative-app announcement illustration.
Color palette: deep navy outlines and panel structure, vivid cobalt blue, soft lavender, peach and warm cream scene accents.
Composition/framing: wide 2:1 composition, all artwork centered with generous clear margins, legible at 384 by 192 points. Keep the shapes large and simple; the project storyboard is the clear focal point.
Background: real transparent alpha channel, fully empty outside and between isolated objects. This must be a PNG cutout suitable for both light and dark macOS surfaces.
Constraints: no words, no letters, no numbers, no logos, no watermark, no faux transparency checkerboard, no backdrop rectangle, no floor, no pedestal, no photorealism, no 3D, no perspective, no drop shadows, no gradients.
